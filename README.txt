NEPTUNE — JOURNEY INTO THE ICE GIANT
Latest prototype: automatic journey playback

1. Extract this ZIP.
2. Open index.html in a modern browser.
3. Press “Play the journey” to move through all six chapters.

The journey timeline advances automatically during playback. You can pause,
resume, replay, choose a chapter, or explore individual chapter controls.
The rotating globe uses surface features that disappear on its far side.

All scripts and styles are included. No installation or server is required.
The NASA facts link opens an external website.

The color sequence is artistic. Interior layers and orbital paths are
schematic; they are not a calibrated color record or scale model.
